# Security policy data directory

This directory intentionally stores **security policy data**, not the runtime
security implementation.

- `pip-audit-ignores.tsv` is the dated allowlist used by `pip-audit` quality
  gates. Each entry must include an expiry date and an operational reason.
- Runtime request/authentication helpers live in `web/security.py`.
- File, command and access-level enforcement lives in `managers/security.py`.
- Security audit artifacts generated by CI or `run_tests.sh` are written under
  `artifacts/security/`, not this directory.

When adding a security control, update the relevant runtime module and keep this
directory limited to policy/configuration data that supports security checks.
